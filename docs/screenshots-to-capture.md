# Какие экраны переснять

Скриншоты на сайте не редактируются — см. «Экраны приложения на сайте» в
`docs/design-system.md`. Поэтому русская версия интерфейса на сайте получается
только одним способом: переключить язык **в приложении** и снять те же экраны
заново.

## Как снимать

- **Ширина 1170 × 2532** (iPhone 12 Pro в режиме адаптива браузера). Все
  прямоугольники кропов посчитаны под неё; при другом размере их придётся
  мерить заново.
- **Целый экран, не кроп.** Даже там, где на сайте видна одна карточка,
  присылайте экран целиком — вырежу сам. Русский текст длиннее английского,
  границы блоков уезжают, и кроп под английскую вёрстку обрежет лишнее.
- **Данные должны выглядеть живыми.** Пустая сетка, `Test31 Account31`, счёт
  0:0 и «расписание пока не заполнено» на сайте читаются как мёртвый продукт.
  Лучше снимать на аккаунте, где что-то происходило.
- Имя файла — любое, лишь бы понятное; сопоставлю по списку ниже.

## Список

Пятнадцать картинок собираются из десяти экранов.

| Экран приложения | Что должно быть видно | Что из него берётся |
|---|---|---|
| Игры → «Общие» | Список игр, минимум три карточки со временем, площадкой, взносом и уровнем | `games-list` — целиком, в рамке телефона |
| Корты → список | Неделя дат сверху, три-четыре площадки со свободными часами | `courts` — целиком; `court-card` — одна карточка |
| Корты → страница площадки | Фото, неделя дат, переключатель длительности, сетка слотов | `venue-booking` — целиком |
| Сообщество → «Тренеры» → тренер | Цена занятия, специализации, где тренирует, контакты | `coach-profile` — целиком |
| Тренер → редактор расписания | Сетка с открытыми, занятыми и закрытыми часами | `coach-schedule` |
| Сообщество → «Игроки», сортировка по совпадению | Три-четыре карточки с процентом совпадения и строкой причин | `best-match` |
| Игра → результат матча | Обе пары, счёт по сетам, изменение рейтинга у каждого | `set-match` |
| Профиль → «Статистика» | Серия результатов, стабильность, сторона корта | `player-streak`, `player-stability` |
| Профиль → «Статистика», ниже | Кольцо форматов и проценты побед по форматам | `game-formats`, `win-by-format` |
| Профиль → сильные стороны | Диаграмма сильных сторон и зон роста | `player-traits` |
| Профиль → карточка игрока | Карточка с фоном, процентом побед и рейтингом | `player-card` |
| Профиль → вкладка «Организатор» | Возвраты аудитории и форматы, на которые возвращаются | `organizer-stats` |

## Что дальше

Кладите файлы в ту же папку, что и прежние захваты. Дальше — прописать новые
имена в `scripts/app-shots.js`, померить кропы по новой вёрстке и
`npm run build:shots`.

Если русские захваты появятся, а английские останутся нужны для `/en`,
`AppShot` придётся вернуть выбор файла по локали — он уже так умел, код лежит
в истории.
